Accessible Name Trace - Test Lab

Use this page with the Screen Reader Inspector side panel to verify the accessible name trace. Click any element below, then check the trace in the panel.

1. Associated Label Elements

Explicit label (for/id)

Inspect the input → expect Associated label elements: "Username Label" (success)

Implicit label (input wrapped in label)

Inspect the input → expect Associated label elements: "Password Label" (success)

Multiple labels (one explicit, one implicit)

Inspect the input → expect Associated label elements containing both "Email" and "(required)"

aria-label overrides associated labels

Inspect the input → expect aria-label wins (success), Associated label elements: Ignored: overridden (info)

Input with no label at all

Inspect the input → expect Associated label elements: Not present (info)

2. Descendant Name Contributions (Text Content)

Button with span that has aria-label overriding its text

Inspect the button → expect Text content: "Save changes" (from the span's aria-label, not the visible "Save")

Button with plain text (no overrides)

Inspect the button → expect Text content: "Click Me" (normal text node)

Button with aria-label overriding all descendants

Inspect the button → expect aria-label: "Close dialog" wins (success), Text content ignored (info)

Link with mixed content (icon aria-label + text) Profile

Inspect the link → expect Text content to include "GitHub" and "Profile"
